# Implementation

1. Bounded worker: minimal typed registry/fixture lint + tests; no clinical registry
   authorship or accepted source changes. Codex independently tests and integrates.
2. Author Planv2 batches in order: front/summary/SOA/diagram; background/objectives;
   design/population; intervention/visits/discontinuation; assessments/events;
   statistics; data/ethics; quality/references/appendices. Keep per-batch evidence.
3. Joint full-coverage/source-obligation audit and independent review, then3R4.

Execution-plus-review: bounded infrastructure provides worker context relief;
Codex owns clinical source interpretation and cross-batch integration. Additional
bounded authorship only when file ownership and source requirements are explicit.
One owner per file. No stage final, no task closure by workers.

Sep8 execution refinement: after batch1 initial delivery, overlap disjoint batch2
authorship with batch1 content repair to reduce waiting bottlenecks. Shared core
and assembler stay Main-owned/read-only. Accept batches in source order; no
phase dependency or medical obligation is skipped. Execution plus independent
review remains the selected mode.
