# WP4 冻结来源与SOP项目复用
**依赖WP1–3；用户政策已批准，不再次询问政策。**

文件范围：full_draft descriptor/_sources_for_chunk、既有source artifacts/检索输入、authoring输入交接、SOP适用确认界面及现有项目配置、引用绑定。复用当前存储，不建设新知识图谱或全文副本库。

步骤：
1. manifest在任务提交前固定source_id/version/hash/role/locator和适用性。每批只消费冻结版本，后加资料新建受影响任务；旧制品不改。
2. 对IB/药理/既往临床/疾病背景逐类检查“文件存在→提取可用→选入候选→输入模型→断言引用”断点；只有真正缺原资料才向用户索取，其他系统自己恢复。
3. 项目资料面板显示SOP批准版本/范围/排除项；一次项目级明确确认写入现有项目配置/记录，普通运营章节复用，不逐段确认。文件名不能代替批准状态，变版或适用范围变化只重问受影响部分。
4. 旧项目方案仍为参考；项目文件、已确认设计、SOP、文献/监管依据、AI建议各自角色。关键剂量、安全、统计取舍不能因SOP已确认而自动决定。
5. 正文引用支持到实际断言，书目实体和内部证据ID分开。没有直接支持则建议或缺口，不给无关span硬绑定。
