# WP3 科学语义与核对覆盖
**依赖WP2；不把Study A修辞特判扩展成产品政策。**

文件范围：full_draft review policy、AI输出normalize/prompt、authoring typed字段/依赖、office_projection.py、GenOfficeFrame核对呈现、内容合同。沿现有统计/设计对象实现，不新建医学规则服务。

步骤：
1. 整理当前typed事实路径目录（来源、类型、可确认方式、依赖章）。支持真正适用的运营/科学决定，复杂estimand/样本量不得塞到exploratory字符串。
2. 移除标题“统计分析”＋关键词“复合策略”的直接冲突判断；同一estimand/同一ICE/同一结局语境对比，不同ICE可不同策略；原文“治疗策略人群”含糊时澄清，不自动改“采用治疗策略”。
3. 目的/终点按组确认，包含“不设置探索性”的适用选择，但不默认所有研究均不设置。已确认设计变更才重开受影响卡。
4. 通用来源支持规则覆盖研究风险、窗口、访视评估、终点、剂量、职责及实施要求；有依据正文保留，无依据部分进入缺口/建议。来源hash正确不能替代断言支持。
5. 核对针对当前Office字节与设计基线，零检查用not_checked；数字在任意段落出现只算线索，不能证明该剂量/样本量一致。展示已定位/待语义核对/未覆盖的范围；分析失败不挡保存。
6. 将横跨概要、目的、SOA、统计的同一问题聚合成一个有定位的科学决定，避免四章重复问同一题。

WP6验收：B06/B07、A05/A07/A09/A10/A18；反例包括纯复合策略、不同ICE不同策略、同ICE真冲突、标题变化、分析人群含糊、零覆盖、无关段落同数字、否定翻转、100→1000。来源版与工件版冻结后独立医学审阅；无模型自证。未确定科学取舍原生ask给选项，其余构建不断。
