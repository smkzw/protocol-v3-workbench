# 验收总包：分层证据，禁止用计数替代产品

## 0. 执行时机
本文件是完成产品后的集中验收包，不要求每完成一个F任务立即运行。F00–F11可用源码证据记implemented并继续依赖实现；F12统一验收。构建中的例外诊断严格遵守 [BUILD_DISCIPLINE](BUILD_DISCIPLINE.md)，不得改一处测一次。

## 1. 四种不同结论
implemented=代码存在；verified=某范围实际检验；accepted=owner将冻结工件与需求核对后接受该范围；release-ready=全部必做验收闭合。NOT_RUN/UNVERIFIED/FAILED/USER_DEFERRED不能写成PASS。
A01–A26继承原验收原文，不删场景。任务对应关系见TASK_INDEX；脚本/测试文件存在不算场景已执行。历史证据可复用但须输入、工件与环境未漂移。

## 2. 测试层级
| 层 | 证明什么 | 不能替代 |
|---|---|---|
| 源码/静态/构建 | 路由、合同、组件可编译、明显问题 | 行为、实际模型、排版 |
| 定向单元/组件 | 正确选择、状态恢复、异常分支 | 真实API/浏览器 |
| API+SQLite+制品 | 持久/并发/幂等/版本绑定 | 手动编辑体验 |
| ego(lite)真实浏览器 | 点击、IME、长文本、导航、输入不丢、原生文件操作 | 医学充分性/Word原生兼容 |
| 实际产品模型 | 真实资料推理、结构纠正、跨研究泛化 | 医学批准 |
| 原生Word/导出 | 输入文字、格式、字段、分页与所选版本一致 | 正式申报批准 |

## 4. 追加桌面V指标（本次用户明确反馈）
V01：1440/1920/2560分别截图+DOM尺寸；桌面双栏，外层无横向溢出。
V02：UI min12px/body min14px，主信息常规16/14；实际computed style，不只CSS文字。
V03：长中文、英文缩略语、长研究名、10+未决问题仍有逻辑bullet；无大段重复AI免责声明。
V04：主动作在可预期位置；等待/失败/缺信息/已有草稿/新候选/冲突各状态有真实出口。
V05：专注模式不重建iframe、不丢selection/dirty；返回后同内容。
V06：关键确认可见；默认预选不自动采用；第二选项实际保存第二项，已确认内容仍可回看。
V07：关键点击≤20、必填自由文本≤5，计数表包含全部人为决策；超标列根因，不删必要科学确认达标。
V08：保存/下载/重开身份一致；未保存下载提示明确；历史下载不替换当前文档。

## 5. 固定合成场景与盲测
复用第十轮有效合成资料，所有新产物写独立case目录并记录project/study/run/document/sha，不用共享/tmp glob取件。选两个有实质差异的研究：给药途径/治疗期/终点类型/盲法或分期不同；至少一个优效且无期中分析的研究，不要求非劣效界值及期中专属alpha消耗/分配确认；样本量计算所需alpha等假设仍按适用合同保留；另一个有需要处理的复杂设计。第三研究保留给独立验证者，生成逻辑不得看到其预期答案后写案例补丁。
病例参数由来源/用户设定或明确合成测试值；合成文件不用于申报。对比预期由需求与来源独立建立，不把现输出当golden。

## 6. 故障矩阵
保存中断/回执丢失/双窗口/服务重启；模型终态失败/结构不合格/活跃unknown；来源不可解析/无文字层；字段缺失/否定/科学冲突；旧候选目标被新编辑覆盖；两研究并发。每个只记录最小复现与原工件，故障注入限隔离环境。
客户端后台轮询是产品行为，可有backoff；工程Agent不得用固定轮次轮询浪费模型或重复派发。

## 7. Word验收
封面字段来自确认值；无模板使用说明/重复textbox/样例中心/无关缩略语；真实签署空白合法。目录/表图目录页码经原生Word更新并保存后重开核实；书签、REF、引用、页眉页脚、章节分节、横向SOA、跨页表头、字体/行距/分页逐项检查。分开记录生成DOCX、Word保存后DOCX、导出PDF及producer/版本/hash。只打开看见页码不等于字段缓存已保存。
现有Office快照原件下载，不因模板修复重生成覆盖用户稿。源模板readonly；渲染器字体替换提示不能忽略或冒称原生一致。
