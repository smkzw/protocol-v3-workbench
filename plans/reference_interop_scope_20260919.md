# 文献与引用功能范围说明（T16 / A22）

日期：2026-09-19 · 适用基线：f36fed1 · 审阅来源：reviews/protocol-v3-requirements-v2

## 已实现并可验收的能力

1. **Word 原生交叉引用域**：成品导出在正文"见表N"处插入真正的 Word REF 域
   （指向表格题注书签 tbl_N），目录为 TOC 域并在 settings.xml 写入
   updateFields——Word 打开时刷新页码与编号。导出回执 `field_diagnostics`
   逐次报告写入的域数量。
2. **表格题注与编号书签**：全部表格带"表N"题注与书签，跨页表头重复，
   宽矩阵横排版式。
3. **证据身份与来源追溯**：章节正文的每条事实绑定 `fact_paths`，AI 候选的
   表格 provenance/脚注只允许引用输入 evidence_unit_id——这是"引用身份"的
   方案内实现：引用指向系统准入的证据单元，而不是自由文本。
4. **参考文献章节维护**：参考文献章按模板载体生成与受控编辑（R3 自由保存），
   变更进入版本历史与核对线索。

## 已有域保存的诊断（A22）

导出/保存不静默破坏已有域：导出回执报告本次写入的域计数；打开文档时
Word 原生 updateFields 负责域刷新。语义工作稿层面不存储用户外部 docx 的
域对象——该往返属于 GenOffice 接入（T07/T10）验收范围，在此之前不声称
"外部 Word 改稿回导"已支持。

## 明确不声称支持的能力

- **EndNote / Zotero 动态互操作**：首版互操作目标未选定（需求修订 C 节
  明确未确认），未做任何测试，因此本系统不声称支持任何第三方文献管理器
  的域刷新或库同步。
- **外部 Word 全文改稿回导**：未验收，不作为首轮交付承诺。
- 静态文字参考文献**不替代**上述域与证据身份能力（防偷换）。

## 后续选择点（需用户拍板）

第三方文献管理器互操作（EndNote 或 Zotero 择一先行）为独立专项，
选中后另立验收场景，不影响当前主链。
