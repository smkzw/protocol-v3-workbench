# OWNER 决策：疾病背景自主外查（2026-10-01，用户亲授）

> 用户原话归纳：测试里出现的疾病背景资料，缺失时不要作为阻断点——系统应具备自主查询外部文献的能力，直接去 PubMed 等文献网站以及知网搜索相关文献，并直接撰写背景信息。这些内容不是药物相关的，理论上都是外部文献可以支撑的。

## 范围界定（关键边界）

| 内容类别 | 处置 |
|---|---|
| 疾病流行病学、疾病负担、诊疗指南、治疗现状（2.1 疾病背景及治疗现状） | **自主外查撰写**（本决策），不再 source_gap 阻断 |
| 同类已上市药物的治疗进展（属治疗现状的一部分，**非研究药物自身**） | 自主外查撰写 |
| **研究药物自身**的作用机制/非临床/既往临床/剂量选择依据 | 维持 source_gap（外部文献不可能支撑，属申办方自有数据） |

## 实现规格（LOOP 实现师执行，单一集成人）

### 1. 新增：外部文献检索服务 `medical_writing_external_literature.py`

- **PubMed E-utilities 优先**（esearch.efetch 公共 API，无 key；仓库既有注释 evidence_design_manifest.py:421 已把"接入 PubMed E-utilities"列为规划，本次落地）：
  - 查询词由已确认研究事实构造（适应症 + 人群关键词，中英映射：适应症中文名→英文检索词可用简单映射表+研究框架里的既有英文术语）；
  - 检索 top 8，按相关性+年份排序；efetch 取摘要；
  - 每条记录：PMID、标题、期刊、年份、摘要、URL，全部落库为新来源类别 `external_literature`（writing_reference 或既有 evidence 体系，选侵入最小者）。
- **知网（CNKI）**：无公开 API——第一版**不做硬集成**，在来源清单里标 `cnki_not_integrated`（诚实呈现能力边界，不伪造"已搜知网"）。留接口位。
- **超时/失败降级**：网络失败或 0 结果时，背景章退回 source_gap 但**注明"外部检索已尝试，无结果/失败"**——这是降级不是阻断常态。
- 引用完整性红线：**每条引用必须真实来自检索响应**（PMID 可回验）；伪造引用=P0。检索响应原文留档（JSON 落盘到 runs 下作证据）。

### 2. 修改：背景章生成规则（medical_writing_full_draft.py:824 一带）

原规则："疾病背景及治疗现状在缺少流行病学、疾病负担、指南或治疗现状来源时必须 source_gap"

新规则：疾病背景及治疗现状章节——项目内来源不足时：
1. **先触发外部文献检索**（上述服务），用检索到的文献作为该章 evidence（标记 `source_class=external_literature`，`needs_medical_confirmation=true` 保留——医学经理保留最终审阅权，但**不再是流程阻断**）；
2. 检索有结果 → 撰写正文，**每处事实带 PMID 引用**（方案正文引用格式：作者/期刊/年份+PMID，进参考文献章）；
3. 检索失败/0 结果 → source_gap + 注明已尝试外查。
4. **研究药物自身内容（2.3）不受此决策影响**，维持原有 source_gap 规则。

### 3. UI 呈现

- 背景章生成后，界面来源区新增"外部文献"分组：逐条列 PMID/标题/年份，可点击展开摘要；
- 整章标记"基于外部文献自动撰写，待医学确认"（沿用 needs_medical_confirmation 既有展示）。

### 4. 测试要求（反例先红后绿）

- T1：适应症给定、项目无流行病学来源 → 触发外查（stub HTTP）→ 背景章正文含真实引用 → content_status=complete（非 source_gap）；
- T2：外查 HTTP 失败 → 退回 source_gap 且注明已尝试；
- T3：外查 0 结果 → 同 T2；
- T4：研究药物机制章缺来源 → 仍 source_gap（边界不放松）；
- T5：引用完整性——stub 响应中的 PMID 与落库/正文引用逐一一致；
- T6：知网标记 cnki_not_integrated 出现在来源清单。

### 5. 与自检门/测试者的关系

- 自检门八节点不变（背景章在⑤初稿内，外查使初稿背景章从空壳变有肉——正是 PV/QA 审阅发现的"背景章空心"的正解）；
- 下轮测试者的医学总监/PV 审阅将真实检验外查撰写的背景质量——这正是"测试者发现科学性问题"的范畴。

## 红线

- 引用真实性（PMID 可回验）高于一切；检索原文留档；
- 研究药物自有数据边界不放松；
- 检索服务本身要设超时（如 30s/次）与每日限额（防滥用），失败降级不重试轰炸；
- 本能力只用于疾病背景类非药物内容，禁止扩展到任何可被外部文献"看起来能支撑"的药物自身声明。
