# R3-E 断点续测指令

你的上一段会话被外部中断了（不是你的错，也不是产品的错）。现在续上：

1. 先读你自己目录里的 `notes.md`（断点纪律要求你每站一行）与 `report.md`（若已有草稿），核对 `screenshots/` 里已有的截图，搞清你走到了哪一站、项目（R3E- 前缀）当时什么状态。
2. 已完成的站**不要重做**；项目已存在就直接在界面里打开它继续，绝不新建重复项目。
3. 从断点的下一站继续执行原任务书 `prompt.md` 的链路与十道关体检单，规矩不变（用户视角铁律／红线／判卡尺／兜底规矩）。
4. 中断期间的空档在报告里如实注明"未连续监看"，墙钟不重置。
5. 写完 report.md 并以单独一行 `EXIT=OK` 结尾，然后按任务书第十一节收尾。
