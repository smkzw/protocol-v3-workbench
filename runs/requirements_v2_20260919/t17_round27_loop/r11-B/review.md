## 一、本轮头条观察：系统从 IB 独立重建出了国际关键程序的设计

r10-A 的设计主轴——**vIGA-AD 治疗成功（0/1 且较基线下降≥2 分）第 8 周主要终点、EASI-75→峰值瘙痒 NRS4→EASI 百分比变化的层级检验、2:1 随机、≥12 岁青少年与成人、赋形剂对照、EASI 3-28/BSA 3-20% 入组窗**——与芦可替尼乳膏**国际关键程序（TRuE-AD）的公开设计要素逐一对应**；而成型方案（国内桥接 III期）用的是 IGA-TS＋192 例的缩小设计。**两条路线都合法：成型方案是中国桥接，r10-A 是国际确证形态。系统没有抄成型方案，也没有抄出格式化的错——它从 IB 重建出了一个当前、主流、可辩护的设计。** 这是基准轮构造目的（IB→独立生成→对照差距）第一次得到完整验证，也是十一轮以来医学总监视角最重要的正面证据。

### 三张清单（同适应症对照）

**A. 成型方案明显更优（系统应学）**
1. **样本量算术自洽与溯源**：具名先例＋保守取值＋数字可复算——r10-A 的 850 与声明假设差 4 倍，复算门必须强制化（r9/r10 两例通过证明系统能做到）。
2. **SoA 访视表**（访视窗＋逐访视评估矩阵）——系统 1.3 仍空。
3. **6.3.5 停药规则操作化**（BSA>20%/清除 3 天/用量超阈）——系统 6.3 空，且外用制剂的用量上限已有（按 BSA 核定）却没接停药规则，一步之遥。
4. **TB 筛查与筛查矩阵**——JAK 类风险项，系统缺失且未写豁免理由。
5. 统计防火墙、SAP 时点、分析集成员定义（系统 9.2 有方法无定义）。
6. 缩略语表、量表附录、参考文献配套。

**B. 系统产出更优或更合理（成型可改进）**
1. **从 IB 独立重建出国际关键程序设计**（vIGA-AD TS＋层级＋2:1＋≥12 岁）——基准轮构造目的首次完整验证；成型作为国内桥接可参考国际形态扩大暴露设计依据的表述。
2. **DMC 章节实质内容**（监测领域＝皮肤恶性肿瘤/光化性角化病/血细胞减少，与 JAK 类风险对齐）——成型 192 例 III期全文无监查安排。
3. **AESI 专项达类水平**＋52 周皮肤肿瘤监测＋暴露-不良反应表。
4. **赋形剂（vehicle）术语与外用操作细节**（薄涂手法、洗手豁免、周用量核定清点）——比成型"安慰剂乳膏"表述更精确。
5. **长期安全延长期的"成功者双盲延续＋未成功者补救路径"设计**——比成型"全部进开放期"更聚焦长期安全性问题（局部免疫抑制），可辩护。
6. **首个零内部标记导出件**＋待补齐 33 行/骨架 7 段（有内容件最低）——洁净度里程碑。
7. 5.5 筛选失败与重新筛选规则首次有内容（复筛新编号规则）。

**C. 双方都弱（讨论点，提交 owner；维持 r8/r9/r10 清单 C 并更新）**
1. 保险与赔偿（双方缺失/空壳）。
2. 版本修订历史（成型无表；系统表列空）。
3. SAE 快速报告时限细节（系统 8.6/14.3 空＋骨架占位邮箱；成型未逐页核验）。
4. PP/分析集成员定义（系统有名无定义；成型无 PP）。
5. **TB 筛查豁免论证**（成型有筛查无豁免讨论；系统无筛查也无豁免讨论——JAK 类风险项两边都没把它说透）。

## 六、结论

本轮是基准轮开始以来信息量最大的一轮：**同适应症对照终于成立，而对照的结果出乎此前的悲观预期——系统从不含设计要素的 IB 出发，独立重建出一个与国际关键程序（TRuE-AD）同构、在 DMC/AESI/外用操作细节上甚至比成型方案更完整的设计**，同时拿下首个零内部标记导出件。但医学总监的底线问题依旧：**样本量"链在数断"（850 vs 需 215，4 倍断裂）、6.3 停药规则空、SoA 空、SAE 报告路径空**——这四件事在成型方案里全有示范，属于"最后一公里"而非能力缺口。建议实现侧：**①样本量复算门强制化（r9/r10 已证明可过，r10-A 证明不强制就会断）→ ②【V1】清偿（第 11 轮）→ ③6.3 停药规则把"用量上限核定"接到"超限停药"（一步之遥）→ ④SoA 表与 SAE 报告路径装配（成型已示范）→ ⑤TB 筛查豁免论证**。另请执行秘书向 r10 测试者核实 RT10 "redose"操作的界面步骤（导出未体现剂量变化，P1-7 观察项）。
