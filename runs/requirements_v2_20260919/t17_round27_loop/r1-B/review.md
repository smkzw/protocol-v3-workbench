### 2. 样本量与事件驱动口径 —— **不符合（P1，本份最重统计缺陷）**
- **系统声明**（概要样本量行/1.1样本量行/5.1/9.1四处逐字同文）："假设赋形剂组第8周vIGA-AD成功率约18%、芦可替尼组约38%；按双侧α=0.05、2:1分配，单侧把握度90%计算约需850例（芦可替尼567/赋形剂283）；考虑15%脱落扩至1000例（约667/333）；该样本量同时满足EASI-75与瘙痒NRS4应答的检验需求。"
- **我的复算**（python3，双侧两比例检验，无连续性校正；命令与原始输出见第四节）：
  - 按假设（38% vs 18%、2:1、双侧α=0.05、90%把握度）所需总例数 ≈ **209例**（试验139/对照70）；等比例分配约201例。
  - 按导出的850例（567/283）实际把握度 ≈ **100.0%**（1000例667/333同样≈100%）。
  - 反算：N=850例可评估、对照18%固定时，90%把握度可检出的最小试验组成功率≈**27.6%**（最小差值约9.6个百分点）——远小于假设的20个百分点差。**假设与结论算术不相容，差约4倍。**
  - 附带两处小账：850×1.15=977.5，"考虑15%脱落扩至1000例"实为+17.6%（凑整可接受、表述不准）；"**单侧把握度**"是错误术语（把握度不分单双侧，双侧0.05检验应写"把握度90%"）。
- **出处缺失**：18%/38%成功率**全文无任何引用**；"同时满足EASI-75与NRS4检验需求"是没有任何支撑数字的断言。与2.3.1/2.3.2（非临床/既往临床全空）互为因果——**证据链断处，正是样本量假设无出处处**。
- **事件驱动口径**：本研究为8周二分类终点，非事件驱动设计，不走事件数口径——这个口径本身正确；成型方案同为非事件驱动。√
- **成型对照**（4.4/11.1）："这是一个探索性Ⅰb/Ⅱa期试验，没有设置假设检验，样本量不是通过正式的计算而产生。所采用的样本量预期将产生足够的安全性和有效性数据以满足进一步开发决策的需要。"——N=32与设计（2组×16，12活跃/4安慰剂）算术自洽，且**诚实**。
- **结论**：**成型更优**。诚实的"没有正式计算"好过与自身假设矛盾的形式化计算。挂账⑨（样本量850断裂，P1-53）在本最新导出件**复验未通过**。

## 四、数字自洽性验算表（本轮实际执行的命令与输出）

命令（python3， NormalDist实现双侧两比例检验；未做连续性校正，连续性校正只会让所需例数更大，不影响结论方向）：

```python
def n_total(p1, p2, ratio=2.0, alpha=0.05, power=0.90):
    z_a = nd.inv_cdf(1-alpha/2); z_b = nd.inv_cdf(power)
    delta = p1-p2
    n2 = (z_a+z_b)**2 * (p1*(1-p1)/ratio + p2*(1-p2)) / delta**2
    return n2*(1+ratio)
# n_total(0.38, 0.18) → 209.2
# power at 567/283 → 100.0%；power at 667/333 → 100.00%
# 850*1.15 = 977.5
# 反算（二分法）：N=850、p2=0.18固定时90%把握度可检出的最小p1 ≈ 27.6%（差值≈9.6个百分点）
```
