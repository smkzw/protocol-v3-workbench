# OWNER 决策：背景章节细节控制三件套（2026-10-01，用户亲授）

> 前置：本文件扩展 [OWNER_DECISION_autonomous_background_20261001.md]（自主外查+综述式三步法）。用户追加三条细节控制要求。

## 1. 篇幅与逻辑设计：以竞品为尺

背景章的**篇幅与分段不拍脑袋**，以竞品方案为标尺：

- **篇幅对标**：检索本项目竞品篮子中已准入的 Protocol，统计其"研究背景/疾病背景及治疗现状"章节的实际段落数与字数分布（中位数与区间），生成的背景章篇幅落在竞品区间内（默认目标=竞品中位数±20%）；
- **逻辑故事线对标**：提取竞品对应章节的行文结构（典型如：疾病定义与流行病学 → 疾病负担/未满足需求 → 现有治疗格局（按线/按代际） → 本研究定位与立题依据），不同适应症线不同（如肿瘤常按线数、慢病常按机制代际）——**采用竞品实际使用的故事线**，而非固定模板；
- **实现落点**：full_draft 背景章 prompt 注入"本适应症竞品背景章的结构画像"（段落骨架+篇幅配额），三步法产出按此画像组织；竞品样本不足（<2份）时用默认学术结构并如实标注 structure_source=default。

## 2. 参考文献引用三件套

### (a) 规范引用格式

- 引文格式纳入**文献管理系统统一管理**（writing_reference 既有书目元数据：PMID/标题/期刊/年份/卷期页——`medical_writing_literature.py` 已能解析 PMID 与 PubMed URL）；
- 正文角标与文末列表由同一引文数据源生成，杜绝正文角标与列表对不上；
- 格式默认双轨：**Vancouver**（国际医学期刊标准）与 **GB/T 7714**（国标）两种输出样式，配置选择，默认 Vancouver；样式函数纯确定性（无模型参与）。

### (b) 文献管理系统体检（趁此梳理）

实现前先跑一次文献管理链路体检，产出体检报告（正常项/缺陷清单）：

1. PMID 解析（URL→PMID、PMID→元数据 efetch）；
2. 书目元数据落库与读取（writing_reference 相关表）；
3. 候选引用绑定（`validate_medical_writing_candidate_citations` / citation_bindings 链路）；
4. 角标渲染与参考文献章生成（export 链路 `process_sources_and_citations`）；
5. 双格式（Vancouver/GB-T 7714）输出的确定性测试（同输入同输出）。
   发现缺陷按反例先红后绿修复——**这本身就是背景外查能力的前置依赖**。

### (c) 参考文献列表格式

- 默认 **Vancouver**（编号顺序引用制，角标 `[n]`），可选 **GB/T 7714-2015**（顺序编码制）；
- 列表按正文首次引用顺序编号；期刊缩写采用 NLM Catalog 标准缩写（efetch 自带 TA 字段优先，缺失时保留全称不猜）；
- 每条含：作者（≤3 位列前三+et al.）、标题、期刊、年；卷（期）：页；PMID。DOI 有则附。

## 3. 测试要求（并入背景外查六条，反例先红后绿）

- T7 篇幅对标：竞品画像（stub 3 份竞品背景章）→ 生成章段落/字数落在画像区间；
- T8 故事线对标：竞品用"按线数"结构 → 生成章同构（段落主题序列一致）；
- T9 引用一致性：正文每个角标 `[n]` 在文末列表有唯一对应项，编号连续、无孤儿；
- T10 双格式：同一引文数据 → Vancouver 与 GB/T 7714 输出均符合各自规范（确定性断言）；
- T11 期刊缩写：TA 字段缺失时保留全称（不猜测）；
- T12 文献系统体检报告落盘（含发现缺陷的修复证据）。

## 红线（继承并扩展）

- 引用真实性 P0 不变（PMID 可回验）；
- 篇幅对标只用于背景类章节，不外溢到其他章节；
- 引文格式化是纯确定性代码，**禁止模型生成引文文本**（模型只选"引哪条"，格式由代码渲染）；
- 竞品借鉴仅限背景类内容与结构，研究药物自身数据边界不变。
