# 0926V1 验收矩阵

本文件是下一轮验收要求，**不是本轮已执行的产品测试结果**。本轮实际隔离观察见verification.json及evidence/。每条执行时记录source_commit、运行build、配置身份、测试数据版本、开始/结束及证据采样时间、命令、退出码、报告路径、实际产物ID/hash和状态。

状态：PASSED / FAILED / BLOCKED / NOT_RUN。KNOWN_FAILURE仅是基线归因，不能替代PASSED；NO_NEW_REGRESSIONS_WITH_KNOWN_FAILURES不等于产品全通过。用户端到端不得通过直接改DB伪造通过；隔离单测及合法集成测试应当照常执行。
