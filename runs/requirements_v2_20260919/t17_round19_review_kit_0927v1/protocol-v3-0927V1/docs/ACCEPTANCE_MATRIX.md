# 0927V1 验收矩阵

以下是待实施验收，不是本轮已全部运行。阶段时间预算是目标，不是承诺。

|编号|场景|期望与证据|
|---|---|---|
|A01|无改动相关失败报告|受影响必测全部pass才给FAST_PASS，不标全库通过|
|A02|测试通过但HEAD从基线前进|验证祖先/变更/环境；不因不相等直接强制全量重采|
|A03|新相关失败与旧失败同node不同内容|不自动归KNOWN；诊断真实原因和当前影响|
|A04|required testcase被skip/xfail|拒绝当作必测通过；不算dissolved|
|A05|另一class同名test或缺少参数|不补足目标必测覆盖|
|A06|收集错误/坏报告/缺报告/零测试/超时|稳定结构化失败，无KeyError；日志保留|
|A07|缺pyflakes/ESLint配置错误/fatal/坏JSON|FAIL或工具BLOCKED，不空列表假绿|
|A08|父目录含两个同名工程|拒绝歧义，明确root|
|A09|CLI/编排器报告协议差一个字符|工具合测立即发现；可重读同一JSON，不重跑suite|
|A10|现场设置含WORKBENCH_*与密钥/代理|离线隔离沙盒不继承，不访问现场路径|
|A11|两个测试互相污染|单跑、最短污染前置、逆序/随机序均通过；资源在teardown释放|
|A12|受影响文件映射不完整|扩大到所属模块并报告未覆盖；不得只--lf|
|A13|锁文件和工具链没有变化|第二个局部周期不重装依赖/下载浏览器|
|A14|测试服务已经健康且身份一致|复用；无需kill所有监听者|
|A15|同端口但源码/配置/数据根不同|拒绝冒充匹配运行时，使用明确自有实例|
|A16|FAST/REPLAY运行|零真实模型冷启/生成，非授权网络拒绝|
|A17|模型只读检查与translation真实评估|只读不chat；仅按需要且授权warm，不自动同时唤醒全部|
|A18|HTTP200但错误模型/空输出|不能标目标模型能力通过；目录不冒充resident|
|A19|复用研究/已保存稿fixture|带schema/源/合同身份并走真实保存；不得SQL伪造批准|
|A20|准备批次首次创建/复用/事实或shortlist变化|真实服务+临时SQLite正负结果正确，非mock业务写入|
|A21|600项研究选择测试|仅元数据即可验证20–30项；不依赖574翻译先完成|
|A22|嵌入Office局部修改保存重开下载|真实内部当前稿及回执一致；外部Word另验|
|A23|两次连续局部修改周期|阶段计时与重复准备次数齐全，必测不削弱|
|A24|模型/prompt/解析合同相关变化|刷新相应LIVE能力集；REPLAY不能替代|
|A25|发布候选|约定全回归/来源/权限/文档质量/真实Word门通过；全库债务不隐匿|
