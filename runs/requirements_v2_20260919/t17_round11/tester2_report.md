## 问题清单（按严重等级列示）

### P0 阻断缺陷

#### 问题 1：全文初稿批量生成因后端 AI 路由白名单约束冲突中断，连锁阻断 Word 导出
- **严重等级**：`P0`
- **问题现象**：在文档编辑平台点击“生成全文初稿”时，后台任务 `protocol_full_draft` 报错中断：
  `全文初稿生成失败：AI task protocol_full_draft requires a product-owned approved direct route: base URL must be one of http://127.0.0.1:8002/v1; allowed routes: mtplx via openai_compatible at http://127.0.0.1:8002/v1 using mtplx-flash-next-optimized-speed...`
  后台调度实际尝试分配了 `opencode-go/deepseek-v4.1-flash`，触发了任务强制要求使用 `http://127.0.0.1:8002/v1` 的白名单安全校验。由于批量初稿无法生成，导致各章节正文空缺，触发了导出组装阶段的断言拦截（`substantive_body_missing`），Word 导出流程无法跑通。
- **截图凭证**：`/tmp/t17_tester2/defect_full_draft_ai_route_error.png`
- **复现步骤**：
  1. 完成阶段一、阶段二建项并例外放行进入写作平台；
  2. 点击右侧 AI 抽屉中的“生成全文初稿”；
  3. 观察面板提示路由校验失败错误；
  4. 点击顶部工具栏“预览 Word”或“正式 Word”，观察提示 `Word 导出已阻断：仍有适用正文章节缺少实质正文`。

#### 问题 2：单字段依据抽屉与推荐卡片直出后端内部对象路径与标识符

  1. 在阶段一“展开单字段修改与依据”展开“依据与局限”时，界面直接展示 Python Pydantic 内部模型字段路径：
     `study_definition · framing.investigational_product`
     `study_definition · framing.study_phase`
     `study_definition · framing.indication`
  2. 在“研究设计推荐包”采用组合候选时，界面提示直接泄露后台临时候选 ID：
     `研究设计（正交维度） · mwprefillcand_7757164636440562 · 修订 5→6`
     `干预与合并治疗模块 · mwprefillcand_14f5b08f196f9783 · 修订 6→7`
     `结局与终点模块 · mwprefillcand_9bc16c2950bbfc4f · 修订 7→8`
  3. 组合采用完成的卡片标题直接暴露未格式化的原始 JSON 字符串：
     `{"design.adaptive_design": {"enabled": false, "features": []}, "design.arms_or_cohorts": ...}`
- **截图凭证**：
  - `/tmp/t17_tester2/defect_internal_identifier_leaks.png`
  - `/tmp/t17_tester2/defect_mwprefillcand_and_raw_json_leak.png`
- **复现步骤**：
  1. 在研究设计引导页面，展开“展开单字段修改与依据”；
  2. 点击任意字段下的“查看候选、依据与局限”，观察依据标签；
  3. 点击任意组合推荐模块下的候选并点击“采用所选方案”，观察采用后的卡片标题与版本审计记录。

### P2 交互与用户体验缺陷

#### 问题 3：正文引文缺少来源反向定位与悬浮卡片交互
- **严重等级**：`P2`
- **问题现象**：在正文中插入引文后，上标呈现为 `[待编号]`，DOM 中正确写入了 `data-reference-ids`，但在富文本编辑器中点击或悬停于该上标时，无任何交互反馈，右侧文献库卡片不会自动聚焦、高亮或展开。
- **截图凭证**：`/tmp/t17_tester2/step73_citation_inserted_in_editor.png`
- **复现步骤**：
  1. 在文献库中导入或录入一篇文献；
  2. 在正文编辑器中点击该文献卡片的“插入引文”；
  3. 鼠标悬停或点击正文中新出现的引文上标，右侧面板无联动。

## 已知局限与环境说明 (KNOWN_LIMITATIONS)

1. **项目总览 HTTP 503 初始阻断**：登录开局“项目总览”提示 `monitoring_principal_unavailable (HTTP 503)`，遵从指令直接进入“医学写作”模块继续，不影响核心功能链路。
2. **全文初稿批量任务 AI 路由白名单约束**：本地部署中，`protocol_full_draft` 任务在安全校验器中硬编码限制必须使用 `http://127.0.0.1:8002/v1` 的 `mtplx` 路由，而服务配置的分发策略调度至外部模型时被网关断言阻断。
3. **Word 导出的正文完整性硬前置依赖**：系统严格遵循临床规范，未生成或采纳正文草稿前，禁止导出半成品正文，从而使初稿生成阻断传导阻断了最终 Word 文件产出。
