# 3R3 batch 6: statistical content obligations

Preparation, not statistical acceptance. Codex reread source body children
757–806 directly; approved TP-MA-07 v2.0 unchanged.

- SAP status/timing and revision linkage (757–760) must match the actual analysis
  and unblinding arrangements. A promised later SAP does not waive protocol-level
  endpoint, estimand, primary method or sample-size requirements.
- Sample size (761–772) needs endpoint, hypotheses, test/model, sidedness and
  alpha, power, assumptions and their evidence, allocation and relevant attrition,
  method/software version and reproducible result. Applicable interim adjustments
  and design effects must be explicit. Not all studies use the same formula.
- Assumptions must align with the selected estimand/analysis, not merely a cited
  competitor's N. Sensitivity to uncertain assumptions and decision provenance
  belong to the high-risk sample-size card, with AI-provided explanation.
- Analysis sets (773–775) require explicit inclusion, grouping and handling rules.
  Randomized participants, treated participants and available assessments are
  not interchangeable. Do not blindly require an available safety assessment to
  discard exposed participants, or omit rescue-treated participants merely
  because the template shows that example.
- Source 777 puts an ANCOVA/MMRM/tipping-point example under analysis sets. Preserve
  the method obligation in the correct semantic carrier; these methods are not
  universally suitable. A sensitivity analysis must address the intended
  assumption/estimand; a different method name alone is not sufficient.
- Source 779 does not make SAS an application dependency. Statistical software
  in a real protocol must reflect the actual analysis arrangements; calculations
  performed by the workbench still require their own reproducibility evidence.
- Descriptive summaries and missing-denominator rules (781) need actual variable
  types and conventions. Missing outcomes and intercurrent events are not synonyms.
- Demographics/baseline, adherence/concomitant treatment, primary main/sensitivity,
  secondary, safety, exploratory and subgroup analyses each need study-specific
  methods and data definitions. Blank headings and “same as previous protocol”
  at 794/796/798 fail substantive acceptance.
- Multiplicity (802–803) must cover the actual confirmatory family, ordering,
  allocations and dependencies; a list of Holm/Hochberg/sequence examples is not
  a selected procedure. No adjustment needed requires a real applicability
  disposition, not a default copied sentence.
- Interim analyses (805–806) require applicable timing/information fraction,
  purpose, rules, decision responsibility and impact on final analysis. Not every
  safety review consumes efficacy alpha. Source reference 14.6 is stale for the
  committee node; resolve the accepted canonical target and distinguish IDMC
  responsibilities from endpoint IRC responsibilities.

Negative fixtures: wrong assumed effect versus source; N without reproducible
inputs; missing sidedness or allocation; mislabeled analysis set; placeholder
sensitivity table; rescue handling inconsistent with estimand; named multiplicity
method without actual family; interim timing/alpha inconsistent with final design.

Schema/fixture checks do not establish statistical validity. E9(R1)/M11 selected
source anchors already recorded in source preparation support subsequent review;
actual project computations and scientific sign-off are separate later evidence.
