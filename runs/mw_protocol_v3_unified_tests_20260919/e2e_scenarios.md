# 端到端测试场景设计（2026-09-19）

三个虚拟但真实感强的研究场景，覆盖不同适应症/药物/期别/设计：

## Scenario A: III期银屑病（当前执行）
- 药物：泰它利普单抗注射液（抗IL-23p19单抗，每8周皮下注射一次）
- 适应症：中重度斑块状银屑病
- 期别：III期
- 设计：随机双盲安慰剂对照优效性，1:1分组，主要终点PASI-100
- 简述要点：III期确证性设计，样本量~500例（250/组），多中心国际研究

## Scenario B: II期2型糖尿病（后续执行）
- 药物：ZL-2101片（GLP-1R/GIP双靶点小分子激动剂，每日口服一次）
- 适应症：2型糖尿病
- 期别：II期
- 设计：多剂量递增+扩展，4组（安慰剂/低/中/高剂量），主要终点HbA1c较基线变化

## Scenario C: IIb期哮喘（后续执行）
- 药物：康纳单抗注射液（抗TSLP单抗，每4周皮下注射一次）
- 适应症：重度未控制哮喘
- 期别：IIb期
- 设计：随机双盲平行组，主要终点年化急性加重率

## 通过标准
每个场景需完成：建项→资料→推荐确认→全部适用章节生成→受控编辑→导出Word（零占位/零模板痕迹/工程语言清理）→一致性门复核
