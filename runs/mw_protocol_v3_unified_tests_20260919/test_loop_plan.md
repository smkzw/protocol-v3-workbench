1. 清洁环境（清除旧项目）
2. T1-T4分别独立测试（不共享发现）
3. 测试完成后，主线程汇总所有问题
4. 会商审阅：审阅问题→深挖根因→举一反三→修复
5. 修复后重新派发测试
6. 循环直到所有测试通过
