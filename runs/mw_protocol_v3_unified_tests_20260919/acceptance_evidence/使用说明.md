# 研究方案工作台 · 使用与验收说明

## 一、平台怎么打开（无需登录）
1. 打开终端，进入本目录，运行：`bash runs/mw_protocol_v3_unified_tests_20260919/start_browser_backend.sh`（保持窗口开着）
2. 另开一个终端，进入 `frontend` 目录，运行：`npx vite --port 5175`
3. 浏览器打开：http://localhost:5175/tests/protocol-intake-functional.html

## 二、完整流程（实测14次点击，只需填写1处文字）
粘贴研究简述 → 准备写作材料 → 确认研究信息/给药建议 → 生成设计要素建议 → 逐卡确认（红色标识的需重点核对）→ 生成完整初稿 → 阅读修改（每段可点"编辑"）→ 保存完整初稿 → 导出Word。

## 五、以后什么时候会重新生成
您修改研究资料或确认内容后（事实真实变化），系统会自动按新基准重新生成受影响的章节并提示您重新核对；没有变化时不会重复生成打扰您。
