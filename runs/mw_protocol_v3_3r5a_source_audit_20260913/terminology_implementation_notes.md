# 3R7A 实施输入，尚未实施/验收

来源：Plan v3 §3R7A、design v1.4 §7、原v2 Task3R7；当前三消费端代码及quality_consumer_probe.json。原v2“受试者为法定禁用词”的表述已被新设计替代：这是当前公司模板新正文首选，不得宣称法规禁止或改写引用原题。

范围最小化：一个terminology/library.py与声明JSON；复用现有finding语义，不建词库服务/数据库。词条记录preferred/variant、适用文本角色、来源。以结构化块角色区分新正文、表格、页眉页脚、法规/文献原题、源引用、模板说明和签署控件。模板说明若进入最终正文报说明泄漏，不能仅跳过后称终稿通过；引用角色仅保留确实有定位的引用片段，不豁免同块其他草稿指令。

定位保留block_id/locator、表格cell_id及字符范围。新正文“受试者”提出替换建议“试验参与者”，不得自动写回原始SOP、引用标题或用户已接受历史版本。“受试者”单词本身不是医学错误，更不是撤销历史验收依据。

数值格式检查必须尊重单位和语境：版本号、方案编号、文献年/页、日期、比值不是千分位数；百分比不得被换成另一数值；区间号处理不得改变负号、不等号和范围开闭；纯文本无法证明字体正体，记录格式检查待Word样式验证，不以字符正则假称字体合格。按源模板/公司明确规则建立建议，无依据不强改所有空格。

缩略语闭环使用实际正文出现与已定义映射，生成列表必须可回到使用块。未知全称显示需核实，不能用词典猜测医学全称；不得把英文药名、单位或所有大写串机械当缩略语。已登记规则与实际实现状态分开，V1的正文消费端必须调用。

正文草稿检查先重放quality_consumer_probe.py中的7个有判别力输入：两个合法流程被旧生成验证器误报，真占位仍被检出。实现后至少覆盖正文/table cell、混合合法+真占位、合法署名控件、引用标题、模板说明泄漏与精确定位，保留现有负向测试。旧三消费者共同迁移到同一函数，避免只修detector；未触达旧链纯历史接口不大幅重构。

本文件不改变当前Trellis3R5A状态。待R03/Word源映射独立复核后，连续激活3R7A并执行；不把准备文档、探针输出算新库实现。
